## 4. Adapter 第一阶段映射建议

1. 建立只读 `mapProductionStateToUiState`，先覆盖上下文、镜头、选择、权限、媒体和生成状态。
2. 用新 Preview Fixtures 对照生产映射，不立即替换旧入口。
3. 建立 `ProductionStoryboardUiActions`，优先接只读导航和选择。
4. 分批接 Prompt 保存、单镜生成、参考资产、移动和批量动作。
5. 最后接帧编辑器、局部重绘、Seedance 和跨站同步。
6. 在功能开关后并行保留旧工作台，完成真实回归再切换。

## 5. 不应误删的隐性客户端行为

- Prompt 编辑时防止实时更新覆盖正在输入的文本。
- signed URL 变化不能误把 generating 清为 idle。
- 按集预取与当前场加载具有不同覆盖语义。
- 跨场移动可能把源场移空，需要真正清理本地幽灵镜头。
- 详情抽屉宽度有持久化边界。
- 文本输入与工作台快捷键有焦点隔离。
- 局部重绘预览在采用/放弃前必须保留原图和草稿。
- 只读权限不仅是按钮禁用，服务端仍需校验。

## 6. 安全集成原则

- 不在当前有未提交改动的分支直接做 Storyboard 全量替换。
- 集成前从干净、最新的 main 创建独立分支或 worktree。
- 旧 Widget 中的业务逻辑先抽取或建立测试，再删除旧展示。
- Contract 与 Adapter 改动独立审查。
- 不把设计师 Package 的 Mock、占位文本或本地资源带入生产数据路径。
