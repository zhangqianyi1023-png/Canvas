# Storyboard 业务能力保留清单

用途：防止完整 UI/UX 重构只保留 API，却遗漏客户端已有业务闭环。设计师负责为已确认能力提供界面和反馈；工程团队负责真实实现。

状态：`v0.1 源码盘点初稿`。最终以产品确认后的 v1.0 为准。

## 1. 上下文与导航

| 编号 | 能力 | UI必须表达 | 工程侧职责 |
|---|---|---|---|
| C-001 | 当前项目上下文 | 项目名称或可识别上下文 | 提供真实项目状态 |
| C-002 | 集/场上下文 | 当前集、场及切换入口 | 加载、切场、权限校验 |
| C-003 | 按场/按集工作范围 | 明确当前范围，防止误批量 | 预取和范围内数据聚合 |
| C-004 | 镜头定位 | 镜头展示编号、选择和滚动定位 | 业务 ID 映射与跨站同步 |
| C-005 | 上一镜/下一镜 | 按钮和键盘反馈 | 选择状态更新 |
| C-006 | 跨场移动镜头 | 目标选择、执行中、成功/失败 | 权限、写入、源/目标刷新 |

## 11. 暂不能由设计师自行删除的能力

在产品负责人明确确认前，以下能力不得因为新原型未画出而删除：

- 列表/卡片视图和详情面板。
- 首尾帧、多参考及历史关键帧兼容。
- Prompt 保存状态。
- 单镜/批量生成。
- 参考资产。
- 帧编辑和局部重绘确认。
- 跨场移动。
- 只读权限。
- Seedance 草稿/上传。
- 键盘选择和 Tooltip。
