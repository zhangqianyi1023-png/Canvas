# Storyboard UI 状态与交互矩阵

本矩阵是视觉验收和 Mock Fixtures 的共同清单。HTML 没有画出的状态也不能省略，应由设计师补齐。

## 1. 工作台级状态

| 状态 | 必须展示 | 允许动作 | 禁止/注意 |
|---|---|---|---|
| loading | 稳定骨架或进度、当前上下文 | 取消可取消动作 | 不闪出假空状态 |
| ready | 镜头集合和当前上下文 | 按权限开放操作 | 不隐藏保存/任务反馈 |
| empty | 空原因和下一步 | 重试、切场或返回 | 不展示虚构镜头 |
| error | 错误摘要、重试 | 重试、切换上下文 | 不清空用户草稿 |
| readOnly | 明确只读提示 | 浏览、预览 | 禁止写操作 |
| noAccess | 受限说明 | 返回/切换项目 | 不展示业务内容 |

## 2. 镜头卡片/列表项

| 状态 | 视觉要求 | 交互要求 |
|---|---|---|
| default | 编号、缩略图、核心摘要 | 单击选择 |
| hover | 可点击区域和快捷动作明确 | 不造成布局跳动 |
| focused | 键盘焦点可见 | Enter/Space 语义明确 |
| selected | 与 hover 明显不同 | 与详情内容一致 |
| multiSelected | 展示批量范围 | 支持取消/扩展选择 |
| dragging | 原位置、拖拽预览清晰 | Esc 可取消 |
| dropTarget | 可放置/不可放置明确 | 不允许静默失败 |
| disabled | 原因可发现 | 不触发回调 |
| stale/update | 如需提示则不遮挡主内容 | 工程侧决定刷新策略 |

## 3. 媒体状态

| 状态 | 图片/视频容器 | 操作 |
|---|---|---|
| missing | 明确占位和生成/添加入口 | 按权限允许动作 |
| loading | 保持尺寸稳定、显示进度或骨架 | 可取消预览打开 |
| ready | 正确比例、裁切规则明确 | 预览/编辑/替换 |
| failed | 错误占位和重试 | `onRetryMedia` |
| generating | 与普通 loading 区分 | 禁止重复提交 |
| localModifying | 明确“局部重绘中” | 保留原图 |
| redrawPreview | 新旧对比、采用/放弃 | 两个动作都可达 |
| unavailable | 鉴权/过期的通用反馈 | 交给工程侧刷新 |

## 4. Prompt 与表单

| 状态 | 必须展示 | 切换镜头时 |
|---|---|---|
| synced | 已同步或无打扰稳定态 | 可切换 |
| dirty | 已修改标记 | 不得静默丢失 |
| saving | 保存中且避免重复提交 | 由工程规则决定是否阻塞 |
| failed | 错误和重试 | 保留本地文本 |
| readOnly | 可复制但不可修改 | 正常切换 |
| generatingPrompt | 生成进度和取消/阻塞状态 | 保留原文本直到结果确认 |

## 5. 生成任务

| 状态 | 文案原则 | 操作 |
|---|---|---|
| pending | “待生成” | 生成 |
| submitting | “正在提交” | 防重复 |
| generating | 区分图片/视频/重绘 | 查看状态，必要时取消 |
| ready | “已出图/已生成” | 预览、重新生成 |
| failed | 显示可理解的失败摘要 | 重试、查看详情 |
| blocked | 明确权限/配额/前置条件 | 修复入口或说明 |

## 6. 参考资产

| 状态 | 必须展示 | 操作 |
|---|---|---|
| empty | 推荐数量/上限和添加入口 | 添加 |
| loading | 固定槽位尺寸 | 暂停编辑或乐观展示由工程决定 |
| ready | 来源、类型、缩略图 | 查看/移除 |
| inherited | 与手动资产可区分 | 按规则覆盖 |
| limitReached | 上限和原因 | 禁止继续添加 |
| syncPending | 自动绑定/刷新中的轻量反馈 | 不清空已有资产 |
| failed | 保留已有资产和错误 | 重试 |

## 7. 面板、弹窗和菜单

| 对象 | 必须覆盖 |
|---|---|
| 详情面板 | closed/open/resizing/min/max |
| 右键菜单 | available/partiallyDisabled/readOnly |
| 删除确认 | 默认焦点、取消、确认、执行中、失败 |
| 移动镜头 | 目标加载、无目标、选择、提交、失败 |
| 批量生成 | 选择为空、部分不可用、确认、执行中、结果摘要 |
| Seedance 上传 | 候选、全选、上传中、部分失败、完成 |
| 帧编辑器 | 打开、处理中、返回草稿、采用、放弃 |

## 8. 窗口和输入矩阵

视觉冻结时至少提供以下尺寸截图：

- `1280 × 800`：最低支持尺寸候选，需双方确认。
- `1440 × 900`：标准笔记本窗口。
- `1728 × 1117`：高分辨率笔记本参考。
- `2560 × 1440`：现有工作台设计基准参考。

输入方式至少覆盖：

- 鼠标单击、双击、右键和拖拽。
- 触控板滚动。
- Tab 焦点移动。
- 上一镜/下一镜快捷键。
- 生成快捷键。
- 文本输入法组合态，不得被全局快捷键截断。
