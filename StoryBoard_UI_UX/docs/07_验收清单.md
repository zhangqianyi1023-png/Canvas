# Storyboard UI/UX 重构验收清单

验收分为 UI 正式验收和生产集成验收。UI 验收通过不等于业务上线完成。

## A. 交接冻结门禁

- [ ] HTML 原型已经归档，可离线运行。
- [ ] 关键尺寸截图完整。
- [ ] PRD 范围和非目标确认。
- [ ] 业务能力保留清单逐项确认。
- [ ] 状态与交互矩阵确认。
- [ ] Contract 升级为 v1.0.0。
- [ ] 字体、图标、图片授权确认。
- [ ] 新增/删除的业务能力已有产品结论。

## B. 设计师 Flutter Package 验收

### B1. 代码边界

- [ ] 仅修改 `storyboard_ui_v2`、经批准的 foundation 和 Preview。
- [ ] 无 Riverpod、HTTP、WebSocket、认证和数据库依赖。
- [ ] 无生产 API 地址、Token、签名 URL 和真实用户数据。
- [ ] 所有生产数据从 `StoryboardUiState` 输入。
- [ ] 所有业务操作通过 `StoryboardUiActions` 输出。
- [ ] 无单一巨型工作台 Widget。

### B2. 场景完整性

- [ ] loading。
- [ ] ready/normal。
- [ ] empty。
- [ ] workspace error。
- [ ] readOnly。
- [ ] noAccess。
- [ ] generating。
- [ ] generation failed。
- [ ] media missing/loading/failed。
- [ ] Prompt dirty/saving/failed。
- [ ] 大量镜头和长文本。

### B3. macOS 交互

- [ ] hover、pressed、focus、selected、disabled 清晰。
- [ ] 单击、双击、右键语义无冲突。
- [ ] 键盘焦点和快捷操作可用。
- [ ] 输入法组合态正常。
- [ ] 滚轮和触控板滚动正常。
- [ ] 拖拽有完整反馈和取消路径。
- [ ] 弹窗有默认焦点、Esc 和安全确认。
- [ ] Tooltip 和可访问标签完整。
- [ ] 调整窗口尺寸不遮挡关键状态/动作。

### B4. 视觉

- [ ] 与冻结 HTML 的整体布局一致。
- [ ] 色彩、字体、字号、间距、圆角、阴影一致。
- [ ] 图标和资源来源一致。
- [ ] 指定尺寸逐张截图对比通过。
- [ ] 不同状态下无布局跳动、溢出和遮挡。
- [ ] 视觉差异已登记并获得确认。

### B5. 质量

- [ ] `dart format` 通过。
- [ ] `flutter analyze` 无 error/warning。
- [ ] 全部测试通过。
- [ ] Preview 无后端可独立启动。
- [ ] Callback Recorder 能观察主要用户动作。
- [ ] `largeProject` Fixture 可用。
- [ ] 已知问题和未完成项写入 CHANGELOG/README。

## C. Hurricane 生产集成验收

- [ ] Adapter 对所有 Contract 字段有明确映射。
- [ ] 现有权限规则没有被 UI 绕过。
- [ ] 场/集切换和镜头选择正确。
- [ ] 图片 Prompt、视频 Prompt 保存与失败恢复正确。
- [ ] 首尾帧、多参考及历史关键帧兼容。
- [ ] 单镜和批量生成防重复提交。
- [ ] 图片/视频任务状态实时更新。
- [ ] 参考资产添加、移除、自动同步正确。
- [ ] 局部重绘预览、采用、放弃闭环正确。
- [ ] 跨场移动后源场和目标场正确刷新。
- [ ] Seedance 草稿和批量上传正确。
- [ ] Final/Project/Jsen 等跨站同步正确。
- [ ] 媒体鉴权、缓存、过期刷新正确。
- [ ] 键盘快捷键与文本输入无冲突。
- [ ] 目标测试、`flutter analyze` 和回归测试通过。
- [ ] 新旧 UI 切换、灰度或回滚方案已验证。
