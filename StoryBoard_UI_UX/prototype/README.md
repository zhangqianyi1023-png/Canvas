# HTML 原型归档说明

当前目录尚未收到设计师 HTML 原型。

请将完整、可离线打开的原型按以下结构归档：

```text
prototype/
├── index.html
├── README.md
├── assets/
├── screenshots/
│   ├── 1280x800/
│   ├── 1440x900/
│   ├── 1728x1117/
│   └── 2560x1440/
└── interactions/
```

设计师需要在本文件追加：

- 原型入口和运行方式。
- 视觉冻结版本号和日期。
- 使用的字体、图标、图片及授权来源。
- HTML 不可表达的 macOS 交互。
- 已知未完成页面/状态。
- 与 PRD 或 Contract 的差异。

不要归档：真实 Token、后端地址、真实用户数据、客户项目素材或未经授权的字体。
