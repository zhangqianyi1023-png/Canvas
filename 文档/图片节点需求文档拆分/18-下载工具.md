# 下载工具需求文档

## 1. 功能目标

让用户下载图片节点中的当前图片。

## 2. 入口

图片节点工具栏点击“下载”。

## 3. 页面元素

- 下载按钮。
- 下载中提示，可选。
- 下载失败提示。

## 4. 交互流程

1. 用户点击下载。
2. 系统获取当前图片文件。
3. 浏览器触发下载。
4. 下载失败时提示用户。

## 5. 多图下载规则

单图节点：

- 下载当前图片。

多图收起态：

- 下载封面图。

多图展开态：

- 点击某一张图片上的下载，下载该图片。

## 6. 实现目的

用于用户把图片保存到本地，便于上传到其他平台或线下使用。

## 7. 开发调研点

- 跨域图片下载。
- 文件名规则。
- data URL 转 Blob。
- 后端代理下载。
- 下载权限控制。
