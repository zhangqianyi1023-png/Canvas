# 上传 / 替换工具需求文档

## 1. 功能目标

让用户把本地图片上传到图片节点，或替换已有图片节点中的图片。

## 2. 入口

- 空图片节点中间的上传按钮。
- 图片工具栏中的上传/替换按钮。
- 拖拽图片文件到节点。
- 粘贴图片到画布或节点。

## 3. 页面元素

空态：

- 上传图标。
- 上传按钮。
- 格式说明。

上传中：

- 上传进度。
- 上传中提示。
- 取消上传，可选。

上传失败：

- 失败提示。
- 重试按钮。

## 4. 交互流程

1. 用户点击上传/替换。
2. 系统打开本地文件选择器。
3. 用户选择图片。
4. 系统校验格式和大小。
5. 图片开始上传。
6. 上传成功后，节点展示新图片。
7. 上传失败时，保留原状态并提示错误。

## 5. 替换规则

已有图片时点击上传，应理解为替换当前图片。

替换后保留：

- 节点位置。
- 节点连接关系。
- 节点标题。
- 节点标记。

替换后更新：

- 图片 URL。
- 图片尺寸。
- 图片比例。
- 图片来源。

## 6. 设计注意点

- 替换是高风险操作，可以在第一版加入确认提示。
- 如果替换会影响下游节点，应提示“下游将引用新图片，但不会自动重新生成结果”。
- 上传失败不能清空原图。

## 7. 开发调研点

- 文件上传服务。
- 支持格式和大小上限。
- 上传后 URL 是否可被模型 API 访问。
- 是否需要生成缩略图。
- 是否需要转存临时图片。
- 粘贴图片和拖拽图片的处理方式。
