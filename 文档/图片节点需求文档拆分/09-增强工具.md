# 增强工具需求文档

## 1. 功能目标

提升图片清晰度、细节质量或人像肤质。

## 2. 入口

图片节点工具栏点击“更多”，再点击“增强”。

## 3. 页面元素

- 增强模式选择。
- 模型选择。
- 放大倍数。
- 增强强度。
- 预估耗时，可选。
- 生成按钮。
- 取消按钮。

## 4. 增强模式

建议第一版支持：

- 超分放大。
- 细节增强。
- 肤质优化。

## 5. 交互流程

1. 用户点击增强。
2. 打开增强面板。
3. 用户选择增强模式。
4. 用户选择模型和参数。
5. 点击生成。
6. 系统生成增强结果节点。

## 6. 实现目的

用于：

- 模糊图片变清晰。
- 小图放大。
- 商品图细节增强。
- 人像皮肤优化。

## 7. 开发调研点

- 哪些模型支持超分。
- 哪些模型支持人像增强。
- 是否有最大放大倍数。
- 处理后图片尺寸如何计算。
- 是否会改变图片内容，需要如何提示用户。
