# 添加到素材库工具需求文档

## 1. 功能目标

让用户把图片节点中的图片保存到素材库，方便后续复用。

## 2. 入口

图片节点工具栏点击“添加到素材库”。

## 3. 页面元素

保存弹窗：

- 图片缩略图。
- 素材名称输入。
- 空间选择：个人 / 团队。
- 文件夹选择。
- 新建文件夹。
- 标签，可选。
- 取消按钮。
- 保存按钮。

保存成功：

- 成功提示。
- 节点可显示“已加入素材库”状态。

## 4. 交互流程

1. 用户点击添加到素材库。
2. 打开保存弹窗。
3. 用户选择空间和文件夹。
4. 用户可修改素材名称。
5. 点击保存。
6. 保存成功后素材库新增图片素材。

## 5. 保存内容

建议保存：

- 图片 URL。
- 图片名称。
- 图片尺寸。
- 来源节点 ID。
- 来源画布 ID。
- 创建人。
- 创建时间。

## 6. 实现目的

用于沉淀可复用图片素材，例如：

- 产品图。
- 角色图。
- 风格参考图。
- 生成结果图。
- 透明背景素材。

## 7. 开发调研点

- 素材库接口。
- 个人空间和团队空间权限。
- 是否复制图片文件，还是只保存引用。
- 临时 URL 是否需要转存。
- 保存失败重试。
