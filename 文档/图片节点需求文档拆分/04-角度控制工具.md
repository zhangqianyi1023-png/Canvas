# 图片节点角度控制工具需求文档

## 1. 文档说明

本文描述图片节点工具栏中的“角度控制”工具。

角度控制不是普通裁剪，也不是简单旋转图片。它的目标是：用户基于一张参考图，通过选择“相机从哪个方向看主体”，让 AI 生成同一主体的新视角图片。

一句话理解：

用户给一张正面产品图，选择“侧面 45°”或拖动 3D 相机控件，系统会把原图、目标视角参数和提示词一起提交给图片生成模型，让模型推断并生成这个主体的新角度图片。

## 2. 功能目标

### 2.1 用户目标

用户可以：

- 打开多角度编辑器。
- 通过快捷视角选择常用角度。
- 通过 3D 控件拖动相机方向。
- 通过滑杆精确调整水平环绕角度。
- 通过滑杆精确调整垂直俯仰角度。
- 通过滑杆调整相机距离。
- 补充文字要求，例如“保持白底”“产品居中”“不要改变衣服颜色”。
- 选择图片 API。
- 选择图片模型。
- 选择输出比例、尺寸、生成张数。
- 点击生成后得到新角度图片节点。

### 2.2 产品目标

角度控制用于解决这些场景：

- 商品图只有正面，需要生成侧面、背面、俯视图。
- 角色图只有一个角度，需要补充角色设定图。
- 物体图需要生成多视角参考，给 3D、视频、海报使用。
- 用户想从同一个主体生成不同构图，而不是重新描述一遍。

### 2.3 设计目标

设计师需要明确：

- 用户点击工具栏按钮后，原工具栏如何变化。
- 多角度编辑器浮层出现在哪里。
- 浮层里面有哪些区域。
- 3D 视角控件如何展示。
- 快捷视角按钮如何排列。
- 滑杆和参数如何布局。
- 生成按钮、重置按钮、关闭按钮在哪里。
- 生成中、错误、禁用状态如何展示。

### 2.4 开发目标

开发需要明确：

- 如何用 UI 表达相机视角。
- 用户拖动 3D 控件后如何得到 yaw / pitch / distance。
- 如何把角度参数转成 AI 能理解的提示词。
- 如何把原图作为参考图传给模型。
- 如何根据模型能力展示可选参数。
- 如何创建新图片节点并保存角度来源信息。

## 3. 功能入口

### 3.1 入口位置

入口位于图片节点选中后的图片工具栏中。

按钮名称：

```text
角度控制
```

按钮建议：

- 使用角度、指南针、相机或 3D 视角相关图标。
- hover 显示 tooltip：角度控制。
- 点击后进入角度控制模式。

### 3.2 展示条件

显示条件：

- 图片节点有可用图片。
- 图片节点是图片结果节点或支持图像编辑的图片节点。
- 图片已经加载成功。

禁用条件：

- 图片为空。
- 图片加载失败。
- 图片正在上传。
- 图片正在生成。
- 没有可用的图生图模型。
- 当前图片来源不支持作为参考图。

### 3.3 点击之后工具栏发生什么

用户点击“角度控制”后：

- 原来的图片工具栏隐藏，避免用户同时点裁剪、打光、扩图等工具。
- 当前节点进入“角度控制编辑态”。
- 图片节点外层可以增加轻微 active 状态，表示正在编辑。
- 页面中出现“多角度编辑器”浮层。
- 浮层和节点之间保持视觉关联，通常出现在图片节点下方或附近。

如果用户再次点击其他工具：

- 应先关闭角度控制浮层。
- 或提示用户当前正在编辑，避免多个编辑器同时打开。

## 4. 多角度编辑器整体布局

### 4.1 浮层形态

多角度编辑器建议是一个浮层，而不是全屏弹窗。

原因：

- 用户仍然需要看到原图片节点。
- 用户需要理解“这个工具正在作用于当前图片”。
- 浮层适合承载相机控件和参数区。

### 4.2 浮层位置

建议：

- 默认出现在图片节点下方。
- 水平居中对齐图片节点。
- 如果下方空间不足，可以自动上移或向左右避让。
- 不应被浏览器边缘裁切。

### 4.3 浮层尺寸

建议桌面端宽度约 760px。

布局：

- 顶部：标题栏。
- 第二行：快捷视角按钮。
- 中部：左侧 3D 预览区，右侧参数控制区。
- 底部：重置、图片 API、模型、生成参数、生成按钮。

### 4.4 浮层结构

多角度编辑器包含：

- 标题栏。
- 快捷视角区。
- 3D 视角预览区。
- 参数控制区。
- 错误提示区。
- 底部生成控制区。

## 5. 标题栏

### 5.1 标题栏元素

标题栏包含：

- 图标。
- 标题：多角度编辑器。
- 关闭按钮。

### 5.2 关闭按钮

点击关闭后：

- 关闭多角度编辑器。
- 不生成图片。
- 不修改原图片。
- 恢复普通图片工具栏。

生成中：

- 关闭按钮应禁用，避免中断状态不一致。

### 5.3 Escape

建议支持：

- 按 Escape 关闭浮层。
- 如果当前打开了某个参数下拉浮层，优先关闭该参数浮层。
- 如果没有二级浮层，再关闭多角度编辑器。

## 6. 快捷视角区

### 6.1 区域位置

快捷视角区位于标题栏下方。

作用：

- 给用户快速选择常用相机角度。
- 降低用户理解 yaw / pitch 的门槛。

### 6.2 快捷视角选项

建议包含：

| 选项 | 含义 | 推荐参数 |
| --- | --- | --- |
| 自定义 | 用户自由调整 | yaw 0°, pitch 0°, distance 4 |
| 正侧面 | 从主体右侧 90° 看 | yaw 90°, pitch 0°, distance 4 |
| 近侧面 75° | 接近侧面的角度 | yaw 75°, pitch 0°, distance 4 |
| 斜侧面 45° | 右前方斜侧视角 | yaw 45°, pitch 0°, distance 4 |
| 近正侧 15° | 正面略偏侧 | yaw -15°, pitch 0°, distance 4 |
| 正面俯拍 | 从正前方偏上看 | yaw 0°, pitch -30°, distance 4 |
| 正面仰拍 | 从正前方偏下看 | yaw 0°, pitch 30°, distance 4 |
| 侧面俯拍 | 从侧上方看 | yaw 90°, pitch -30°, distance 4 |
| 侧面仰拍 | 从侧下方看 | yaw 90°, pitch 30°, distance 4 |

### 6.3 点击快捷视角后的行为

用户点击某个快捷视角后：

- 该按钮进入 active 状态。
- 3D 预览中的相机移动到对应位置。
- 水平环绕滑杆同步更新。
- 垂直俯仰滑杆同步更新。
- 相机距离滑杆同步更新。
- 预览变化需要有平滑动画，不要瞬间跳变。

### 6.4 自定义状态

当用户手动拖动 3D 控件或滑动任一滑杆后：

- 当前视角切换为“自定义”。
- 快捷视角按钮中“自定义”进入 active 状态。
- 原先选中的快捷视角取消 active。

## 7. 中部布局

### 7.1 左侧：3D 视角预览区

左侧用于展示“相机如何看主体”。

它不是最终生成结果预览，而是一个“相机控制器”。

用户需要通过它理解：

- 相机在主体前后左右哪个方向。
- 相机是俯视还是仰视。
- 相机距离主体远还是近。

### 7.2 右侧：参数控制区

右侧用于精确控制参数。

包含：

- 水平环绕。
- 垂直俯仰。
- 相机距离。
- 提示词输入框。

### 7.3 为什么这样布局

左侧是直觉操作，右侧是精确操作。

用户可以：

- 先用左侧拖动大概方向。
- 再用右侧滑杆微调。
- 最后用提示词补充语义要求。

## 8. 3D 视角预览区

### 8.1 预览内容

3D 视角预览区建议包含：

- 参考图片平面或主体占位。
- 目标相机模型。
- 相机朝向线。
- 相机轨道或空间参考线。
- 方向按钮。
- 视图模式切换。

### 8.2 视图模式

建议支持两种预览模式：

- 透视。
- 正面。

透视：

- 更像 3D 空间。
- 适合理解相机在空间中的位置。

正面：

- 更像二维控制面板。
- 适合看清 yaw / pitch 的相对位置。

切换要求：

- 点击“透视”或“正面”按钮切换。
- 切换时需要有动画。
- 切换不改变 yaw / pitch / distance，只改变预览观察方式。

### 8.3 拖拽操作

用户可以在 3D 预览区拖动来改变相机方向。

拖动规则：

- 横向拖动：改变水平环绕 yaw。
- 纵向拖动：改变垂直俯仰 pitch。
- 拖动时实时更新相机位置。
- 拖动后快捷视角变为自定义。

推荐映射：

- 鼠标向右拖动，相机绕主体向右移动。
- 鼠标向左拖动，相机绕主体向左移动。
- 鼠标向上拖动，相机升高，形成俯视。
- 鼠标向下拖动，相机降低，形成仰视。

### 8.4 四向微调按钮

预览区可以提供四个方向按钮：

- 向左旋转。
- 向右旋转。
- 向上移动相机。
- 向下移动相机。

建议步进：

- 左右每次 15°。
- 上下每次 10°。

作用：

- 给不擅长拖拽的用户一个更可控的操作方式。
- 方便微调。

### 8.5 角度限制

水平环绕：

- 范围建议：-180° 到 180°。

垂直俯仰：

- 范围建议：-60° 到 60°。

原因：

- 过高或过低的角度，AI 很难可靠推断。
- 过极端的视角容易导致主体结构崩坏。

相机距离：

- 范围建议：1 到 8。

含义：

- 1 到 2.5：特写。
- 2.5 到 6：中景。
- 6 到 8：远景。

### 8.6 预览区提示

预览区可以展示简短提示：

```text
拖动控制相机视角
```

但不要写太长的说明，避免遮挡 3D 控件。

## 9. 参数控制区

### 9.1 水平环绕

字段名：

```text
水平环绕
```

控件：

- 滑杆。
- 数值显示。

范围：

```text
-180° 到 180°
```

含义：

- 0°：正前方。
- 45°：右前方斜侧。
- 90°：右侧面。
- 180° 或 -180°：背面。
- -45°：左前方斜侧。
- -90°：左侧面。

### 9.2 垂直俯仰

字段名：

```text
垂直俯仰
```

控件：

- 滑杆。
- 数值显示。

范围：

```text
-60° 到 60°
```

含义：

- 0°：平视。
- 负数：相机升高，形成俯视。
- 正数：相机降低，形成仰视。

这里要注意，用用户能理解的话讲：

- “俯视”不是主体低头，而是相机在上方看主体。
- “仰视”不是主体抬头，而是相机在下方看主体。

### 9.3 相机距离

字段名：

```text
相机距离
```

控件：

- 滑杆。
- 文案标签。

范围：

```text
1 到 8
```

展示文案：

- 特写。
- 中景。
- 远景。

含义：

- 特写：主体更大，占画面更多。
- 中景：保持正常构图。
- 远景：主体更小，画面环境更多。

### 9.4 提示词输入

字段名：

```text
提示词
```

占位文案：

```text
补充主体、背景或构图要求...
```

用户可以输入：

- 保持白色背景。
- 产品居中。
- 不要改变颜色。
- 保持同一人物。
- 保持服装材质。
- 背景干净。
- 不要新增文字、水印。

提示词不是必填。

如果不填，系统也会根据角度参数生成内置提示词。

## 10. 底部生成控制区

### 10.1 重置参数

按钮：

```text
重置参数
```

点击后：

- preset 回到自定义。
- 水平环绕回到 0°。
- 垂直俯仰回到 0°。
- 相机距离回到 4。
- 清空补充提示词。
- 清空错误信息。

重置不需要二次确认。

### 10.2 图片 API

用于选择调用哪个图片服务。

展示：

- 当前 API 名称。
- 如果未配置，显示“未配置 API”。

点击后：

- 打开 API 列表。
- 用户可以切换 API。

切换后：

- 模型列表随 API 更新。
- 如果当前模型不属于新 API，自动切换到默认模型。

### 10.3 模型选择

用于选择执行图生图的新角度生成模型。

要求：

- 只展示支持参考图生成或 image-to-image 的模型。
- 不支持参考图的模型禁用或不展示。
- 模型选择器需要支持搜索，避免模型过多难找。
- 模型项建议展示模型名称、供应商、能力标签。

### 10.4 角度生成参数

点击“角度生成参数”后打开参数浮层。

包含：

- 比例。
- 尺寸。
- 张数。

#### 比例

常见选项：

- 智能。
- 1:1。
- 3:4。
- 4:3。
- 9:16。
- 16:9。

默认建议：

- 智能。

智能含义：

- 由系统或模型根据原图和场景决定。

#### 尺寸

常见选项：

- 1K。
- 2K。
- 4K。

是否展示取决于模型能力。

#### 张数

可选：

- 1 张。
- 2 张。
- 3 张。
- 4 张。

默认：

- 1 张。

### 10.5 生成按钮

按钮文案：

```text
生成新角度图片
```

按钮需要展示预计消耗，例如：

```text
8
```

点击后：

- 校验 API 和模型。
- 组装提示词。
- 提交生成任务。
- 进入生成中状态。

生成中：

- 按钮 loading。
- 所有参数控件禁用。
- 关闭按钮禁用。

## 11. 用户完整交互流程

### 11.1 快捷视角生成

1. 用户选中图片节点。
2. 用户点击工具栏“角度控制”。
3. 原图片工具栏隐藏。
4. 多角度编辑器浮层出现。
5. 用户点击“斜侧面 45°”。
6. 3D 预览相机移动到右前方 45°。
7. 水平环绕显示 45°。
8. 垂直俯仰显示 0°。
9. 用户选择模型和参数。
10. 用户点击“生成新角度图片”。
11. 系统提交原图和角度提示词。
12. 系统生成新图片节点。

### 11.2 拖拽自定义角度生成

1. 用户打开多角度编辑器。
2. 用户在 3D 控件中拖动相机。
3. 系统实时更新 yaw 和 pitch。
4. 快捷视角切换为“自定义”。
5. 用户输入补充提示词。
6. 用户选择输出 2 张。
7. 点击生成。
8. 系统生成 2 张新角度结果。

### 11.3 参数调整流程

1. 用户打开“角度生成参数”。
2. 用户选择 16:9。
3. 用户选择 2K。
4. 用户选择 4 张。
5. 参数入口显示摘要：16:9 · 2K · 4张。
6. 用户点击生成。

## 12. AI 实际拿到的是什么

这是这个工具最重要的点。

用户在界面上选择角度，本质上不是直接把 3D 模型传给 AI。大多数图片生成模型并不能真正读取“相机控件”。系统需要把用户操作转成模型能理解的输入。

AI 通常拿到三类信息：

1. 原始参考图。
2. 目标视角参数。
3. 根据参数生成的文字提示词。

### 12.1 原始参考图

原图作为 image-to-image 参考图传给模型。

作用：

- 保持同一个主体。
- 保持外观、颜色、材质、服装、风格。
- 给模型提供可见结构。

传给 API 的通常是：

```json
{
  "image_urls": ["原图地址"]
}
```

### 12.2 目标视角参数

系统内部需要保存结构化参数：

```json
{
  "presetId": "side45",
  "presetLabel": "斜侧面45°",
  "horizontalAngle": 45,
  "pitchAngle": 0,
  "distance": 4
}
```

这些参数用于：

- UI 回显。
- 生成提示词。
- 保存到结果元数据。
- 后续追溯这张图是怎么生成的。

### 12.3 给 AI 的提示词

系统需要把角度参数转成自然语言。

例如用户选择：

```text
斜侧面45°，水平环绕 45°，垂直俯仰 0°，中景
```

系统可以转成：

```text
请基于参考图生成同一主体的新视角图片。
参考图说明：第一张图片是原始主体，请把它作为身份、结构、材质、服装、颜色、风格和光照的主要依据。
目标视角：斜侧面45°：相机绕主体向右移动到约 45 度位置，从主体右侧方向观察，保持平视；主体自身不要旋转、不要改变姿态。
镜头距离：中景，距离控制值 4.0。
一致性要求：保持同一个主体，不要改变主体类型、脸部/物体特征、服饰、材质、主色、图案和整体美术风格。
补全要求：当目标视角出现原图不可见区域时，请合理推断背面、侧面、顶部或底部结构，保持与参考图逻辑一致。
构图要求：单主体清晰居中，背景尽量贴近参考图或保持干净，不要新增无关主体、文字、水印、边框或多余装饰。
```

如果用户填写了补充提示词：

```text
保持白色背景，产品居中，不要改变 logo
```

则追加：

```text
补充要求：保持白色背景，产品居中，不要改变 logo。
```

### 12.4 不要误导用户

产品文案中不要暗示：

- 系统一定已经真实重建了 3D 模型。
- AI 一定能准确生成完整背面。
- 角度一定能做到几何级准确。

更准确的表达是：

- 系统基于参考图和目标视角生成新角度图片。
- 不可见区域由模型合理推断。
- 结果可能需要用户二次挑选或重试。

## 13. 输出结果

### 13.1 生成新图片节点

点击生成后，结果应创建为新的图片节点。

规则：

- 不覆盖原图。
- 新节点出现在原图片节点右侧或下游方向。
- 原节点与新节点自动连线。
- 新节点自动选中。

### 13.2 新节点标题

建议标题：

```text
角度控制结果
```

如果要更具体：

```text
斜侧面45°结果
```

### 13.3 多张结果

如果用户选择生成多张：

- 可以生成一个多图结果节点。
- 第一张作为默认封面。
- 用户可展开查看全部。
- 用户可设为封面。
- 下游默认读取封面图。

### 13.4 结果元数据

新节点建议保存：

```json
{
  "imageSource": "perspective",
  "perspectiveSourceNodeId": "来源图片节点 ID",
  "perspectiveSourceImageIndex": 0,
  "perspectivePresetId": "side45",
  "perspectiveHorizontalAngle": 45,
  "perspectivePitchAngle": 0,
  "perspectiveDistance": 4,
  "imagePrompt": "最终提交给 AI 的提示词",
  "imageModel": "使用的模型",
  "imageApiId": "使用的 API",
  "imageSize": "16:9",
  "imageResolution": "2k",
  "imageCount": 1
}
```

## 14. 推荐实现方式

### 14.1 前端 UI 层

推荐使用三个层次：

1. 工具栏入口。
2. 多角度编辑器浮层。
3. 3D 相机预览组件。

工具栏入口负责：

- 打开和关闭角度控制。
- 控制普通图片工具栏隐藏。
- 保证不会和其他编辑工具同时打开。

多角度编辑器负责：

- 快捷视角。
- 滑杆参数。
- 提示词。
- API / 模型 / 参数选择。
- 提交生成。

3D 相机预览组件负责：

- 展示相机位置。
- 支持拖拽。
- 支持方向按钮微调。
- 输出 yaw / pitch / distance。

### 14.2 3D 控件推荐方案

推荐使用 Three.js。

原因：

- 可以清楚表达相机在 3D 空间里的位置。
- 可以复用到打光工具、视频重拍工具。
- 可做透视/正面视图切换动画。

3D 控件不需要真的重建图片主体的 3D 模型。

一期可以用：

- 图片平面。
- 简化主体占位。
- 相机模型。
- 相机轨道。
- 相机朝向线。

这样用户能理解“我要从哪里看”，即可满足交互目标。

### 14.3 参数状态管理

建议状态：

```json
{
  "presetId": "custom",
  "horizontalAngle": 0,
  "pitchAngle": 0,
  "distance": 4,
  "instruction": "",
  "providerId": "",
  "model": "",
  "size": "auto",
  "resolution": "2k",
  "count": 1
}
```

### 14.4 提示词构建

推荐使用独立函数构建提示词。

输入：

- presetId。
- presetLabel。
- horizontalAngle。
- pitchAngle。
- distance。
- instruction。
- imageSize。

输出：

- 最终提交给模型的 imagePrompt。

这样做的好处：

- UI 和 prompt 逻辑分离。
- 后续容易测试。
- 不同模型可以复用同一套描述。

### 14.5 模型调用方式

推荐走 image-to-image。

提交内容：

- 原图 URL。
- 最终提示词。
- 模型。
- 比例。
- 尺寸。
- 张数。

示例：

```json
{
  "prompt": "最终角度控制提示词",
  "model": "gpt-image-2",
  "image_urls": ["原图 URL"],
  "size": "16:9",
  "resolution": "2k",
  "n": 1
}
```

### 14.6 如果模型支持结构化相机参数

如果未来某个模型真的支持结构化相机控制，应优先使用结构化参数。

例如：

```json
{
  "camera": {
    "yaw": 45,
    "pitch": 0,
    "distance": 4
  }
}
```

但在没有确认模型支持前，不能假设 API 支持这种字段。

一期推荐：

- 内部保存结构化参数。
- 对外调用时转成提示词。
- 同时把原图作为参考图。

## 15. 生成中状态

### 15.1 生成中 UI

点击生成后：

- 生成按钮显示 loading。
- 文案可以变成“生成中”。
- 快捷视角按钮禁用。
- 滑杆禁用。
- 提示词禁用。
- API、模型、参数禁用。
- 关闭按钮禁用。

### 15.2 生成失败

失败时：

- 浮层保持打开。
- 用户输入和参数不丢失。
- 显示错误信息。
- 生成按钮恢复可点击。

错误示例：

```text
角度控制生成提交失败
```

更友好的文案：

```text
新角度图片生成失败，请检查模型配置后重试。
```

### 15.3 生成成功

成功后：

- 关闭多角度编辑器。
- 创建新图片节点。
- 新节点选中。
- 原图保留。

## 16. 错误和边界场景

### 16.1 没有可用模型

场景：

- 没有配置图片 API。
- 当前 API 没有图片模型。
- 当前模型不支持参考图。

提示：

```text
没有可用的参考图编辑模型，请先在设置里配置图片模型。
```

### 16.2 来源图片不存在

场景：

- 用户打开浮层后，来源节点被删除。

提示：

```text
来源图片已不存在。
```

### 16.3 当前图片不支持视角调整

场景：

- 当前节点不是图片结果节点。
- 当前节点没有可用 imageUrl。

提示：

```text
当前图片不支持视角调整。
```

### 16.4 生成效果不符合预期

角度控制依赖模型推断，不保证每次都准确。

产品需要允许：

- 重新生成。
- 调整角度再生成。
- 补充提示词再生成。
- 多生成几张供用户挑选。

### 16.5 极端角度

如果用户选择背面、强俯视、强仰视：

- 模型需要推断大量不可见区域。
- 结果更容易不稳定。

建议：

- 不禁止极端角度。
- 但后续可在 UI 中提示“该角度需要模型推断更多不可见区域”。

## 18. 开发验收标准

### 18.1 打开和关闭

- 点击角度控制后，普通工具栏隐藏。
- 多角度编辑器出现。
- 点击关闭后浮层关闭。
- 按 Escape 可以关闭浮层。

### 18.2 快捷视角

- 点击快捷视角后，按钮 active。
- yaw / pitch / distance 同步更新。
- 3D 预览相机位置同步更新。
- 手动拖动后切换为自定义。

### 18.3 3D 控件

- 横向拖动改变水平环绕。
- 纵向拖动改变垂直俯仰。
- 左右按钮每次调整 15°。
- 上下按钮每次调整 10°。
- pitch 不超过 -60° 到 60°。

### 18.4 参数

- 水平环绕滑杆可调整 -180° 到 180°。
- 垂直俯仰滑杆可调整 -60° 到 60°。
- 相机距离可调整 1 到 8。
- 提示词可以输入并提交。
- 参数摘要正确显示比例、尺寸、张数。

### 18.5 生成

- 没有可用模型时不能生成。
- 点击生成后提交原图 URL。
- 点击生成后提交最终角度提示词。
- 生成结果创建新图片节点。
- 新节点记录角度参数。
- 原图不被覆盖。

## 19. 测试用例建议

### 19.1 快捷视角测试

- 打开角度控制。
- 点击“斜侧面45°”。
- 检查 horizontalAngle 为 45。
- 检查 pitchAngle 为 0。
- 检查 active 状态正确。

### 19.2 自定义拖拽测试

- 打开角度控制。
- 拖动 3D 预览。
- 检查 presetId 变为 custom。
- 检查 yaw / pitch 有变化。

### 19.3 参数生成测试

- 输入补充提示词。
- 选择 16:9、2K、2 张。
- 点击生成。
- 检查提交参数中包含 size、resolution、count。

### 19.4 提示词测试

- 选择侧面 90°。
- 点击生成。
- 检查最终 prompt 包含“相机绕主体向右移动到约 90 度位置”。
- 检查 prompt 包含一致性要求和补全要求。

### 19.5 无模型测试

- 清空图片模型配置。
- 点击生成。
- 应显示没有可用模型的错误。
- 不应创建结果节点。

## 20. 后续扩展

后续可以考虑：

- 支持背面快捷视角。
- 支持左侧/右侧分别选择。
- 支持保存常用角度预设。
- 支持一次生成 3x3 多角度参考图。
