# 图片节点标注工具需求文档

## 1. 文档说明

本文描述图片节点工具栏中的“标注”工具。

这里的“标注”是指在图片上画批注，例如画箭头、画框、圈重点、写文字说明，然后把原图和批注层合成为一张新的图片。

注意：本文的“标注”不是画布节点的“颜色标记”。颜色标记是给节点打分类标签；图片标注是直接在图片内容上添加视觉说明。

一句话理解：

用户点击图片节点的“标注”，图片上出现一层可以绘制的透明画布，用户可以画线、箭头、框、圆、文字说明，最后点击完成，系统生成一个“批注结果”图片节点。

## 2. 功能目标

### 2.1 用户目标

用户可以：

- 进入图片标注模式。
- 使用画笔自由绘制。
- 使用箭头指出重点位置。
- 使用矩形框选区域。
- 使用圆形圈出区域。
- 添加文字说明。
- 使用橡皮擦除批注。
- 选择批注颜色。
- 调整线宽。
- 撤销和重做操作。
- 取消标注，不生成结果。
- 完成标注，生成新的批注结果图片节点。

### 2.2 产品目标

标注工具解决的是“沟通”和“指示”问题。

典型场景：

- 用户想告诉同事“这里要改”。
- 用户想圈出图片中的主体。
- 用户想用箭头指向某个元素。
- 用户想在图片上写修改意见。
- 用户想把带说明的图片传给下游 AI 节点，让 AI 理解要改哪里。

### 2.3 设计目标

设计师需要明确：

- 点击标注后，原工具栏如何变化。
- 标注工具栏出现在哪里。
- 工具栏分为哪些组。
- 每个工具的 icon 和 active 状态是什么。
- 颜色选择器如何展示。
- 线宽滑杆如何展示。
- 撤销、重做、完成、取消如何表达。
- 文字输入框如何出现。
- 导出中和失败状态如何展示。

### 2.4 开发目标

开发需要明确：

- 标注层如何覆盖在图片上。
- 画笔、箭头、矩形、圆形、文字如何绘制。
- 橡皮如何擦除批注层。
- 撤销/重做如何保存历史。
- 如何处理画布缩放和设备像素比。
- 如何把原图和批注层合成一张 PNG。
- 如何上传批注结果并创建新节点。

## 3. 功能入口

### 3.1 入口位置

入口位于图片节点工具栏的“更多”菜单中。

入口名称：

```text
标注
```

点击路径：

1. 用户选中图片节点。
2. 点击图片工具栏中的“更多”。
3. 点击“标注”。

### 3.2 展示条件

显示条件：

- 图片节点有可用图片。
- 图片加载成功。
- 当前节点支持图片工具。

禁用条件：

- 图片为空。
- 图片正在上传。
- 图片正在生成。
- 图片加载失败。
- 图片跨域导致无法导出批注结果。

### 3.3 点击之后发生什么

用户点击“标注”后：

- 普通图片工具栏隐藏。
- 图片节点进入标注编辑态。
- 图片上覆盖一层透明 canvas 批注层。
- 页面顶部或节点上方出现标注专用工具栏。
- 默认工具为“画笔”。
- 默认颜色为红色。
- 默认线宽为 8。

## 4. 标注编辑态整体布局

### 4.1 页面结构

标注编辑态包含：

- 原图片显示层。
- 透明批注绘制层。
- 标注工具栏。
- 文字输入框，只有使用文字工具时出现。

### 4.2 原图片显示层

原图片保持不变。

要求：

- 图片内容不被直接修改。
- 用户绘制的是覆盖在图片上方的批注层。
- 取消标注后，原图不产生任何变化。

### 4.3 批注绘制层

批注层是一个透明 canvas。

要求：

- 尺寸与图片显示区域一致。
- 跟随图片节点缩放。
- 支持高分屏清晰绘制。
- 不触发画布拖拽。
- 不触发节点拖拽。

### 4.4 标注工具栏

工具栏通过 portal 浮在节点上方。

推荐分组：

第一组：

- 取消。

第二组：

- 画笔。
- 箭头。
- 矩形。
- 圆形。
- 文字。
- 橡皮。
- 颜色。
- 线宽。
- 撤销。
- 重做。

第三组：

- 完成。

## 5. 标注工具栏详细说明

### 5.1 取消

按钮文案：

```text
取消
```

点击后：

- 退出标注编辑态。
- 丢弃当前批注层。
- 不生成新图片节点。
- 原图片不变。
- 普通图片工具栏恢复。

取消不需要二次确认。

但如果用户已经画了内容，后续可以考虑提示：

```text
确定取消标注吗？当前绘制内容不会保存。
```

### 5.2 画笔

画笔用于自由绘制线条。

交互：

- 点击画笔按钮后，画笔进入 active 状态。
- 用户按住鼠标或触控笔拖动，在图片上绘制连续线条。
- 线条颜色使用当前颜色。
- 线条粗细使用当前线宽。

适用场景：

- 手绘圈重点。
- 简单划线。
- 自由写字。

### 5.3 箭头

箭头用于指向图片中的某个位置。

交互：

- 点击箭头按钮后，箭头工具 active。
- 用户按下鼠标确定起点。
- 拖动到目标位置。
- 松开后生成箭头。

规则：

- 起点是箭头尾部。
- 终点是箭头头部。
- 拖动过程中应实时预览箭头。
- 线宽影响箭头杆和箭头头大小。

适用场景：

- 指出需要修改的位置。
- 指向按钮、人物、商品细节。

### 5.4 矩形

矩形用于框选区域。

交互：

- 点击矩形按钮后，矩形工具 active。
- 用户按下鼠标确定矩形起点。
- 拖动到终点。
- 松开后生成矩形边框。

规则：

- 只画边框，不默认填充。
- 颜色使用当前颜色。
- 线宽使用当前线宽。
- 拖动过程中实时预览矩形。

适用场景：

- 框出需要修改的区域。
- 框出 UI 中某个模块。
- 框出商品局部。

### 5.5 圆形

圆形用于圈出区域。

交互：

- 点击圆形按钮后，圆形工具 active。
- 用户按下鼠标确定起点。
- 拖动到终点。
- 松开后生成椭圆边框。

规则：

- 根据拖拽区域生成椭圆。
- 不强制正圆。
- 只画边框，不默认填充。
- 拖动过程中实时预览。

适用场景：

- 圈出重点。
- 标记人物、商品、按钮、瑕疵点。

### 5.6 文字

文字工具用于在图片上添加文字说明。

交互：

1. 用户点击文字工具。
2. 文字工具 active。
3. 用户点击图片上的某个位置。
4. 该位置出现文字输入框。
5. 用户输入文字。
6. 按 Enter 确认，或输入框失焦确认。
7. 按 Escape 取消当前文字输入。

规则：

- Shift + Enter 可以换行，若实现成本高，一期可只支持 Enter 确认。
- 空文字不生成内容。
- 文字颜色使用当前颜色。
- 字号根据线宽映射。
- 文字确认后烘焙到批注层，不再作为可编辑文本对象。

适用场景：

- 写修改意见。
- 写“这里改成红色”。
- 写“删除这个元素”。

### 5.7 橡皮

橡皮用于擦除批注层，不擦除原图。

交互：

- 点击橡皮按钮后，橡皮工具 active。
- 用户拖动时擦除经过区域的批注内容。
- 原图不受影响。

规则：

- 橡皮大小使用当前线宽。
- 橡皮只作用于批注层。
- 橡皮操作可撤销。

### 5.8 颜色

颜色按钮显示当前颜色。

点击后打开颜色面板。

建议颜色：

- 红色：#ff3434。
- 黄色/橙色：#ffb020。
- 绿色：#28d17c。
- 蓝色：#4aa3ff。
- 白色：#ffffff。

交互：

- 点击颜色按钮打开颜色面板。
- 点击颜色后更新当前颜色。
- 颜色面板关闭。
- 当前选中的颜色需要有 selected 状态。

颜色适用对象：

- 画笔。
- 箭头。
- 矩形。
- 圆形。
- 文字。

橡皮不使用颜色。

### 5.9 线宽

线宽使用滑杆。

范围建议：

```text
3 到 28
```

影响对象：

- 画笔线条粗细。
- 箭头粗细和箭头头大小。
- 矩形边框粗细。
- 圆形边框粗细。
- 橡皮擦除大小。
- 文字字号。

### 5.10 撤销

撤销用于回退上一步绘制操作。

规则：

- 没有可撤销内容时禁用。
- 每次完成一次绘制后，保存一个历史快照。
- 文字确认后作为一次操作。
- 橡皮擦除后作为一次操作。

### 5.11 重做

重做用于恢复刚撤销的操作。

规则：

- 没有可重做内容时禁用。
- 用户撤销后，如果执行新的绘制操作，重做历史清空。

### 5.12 完成

按钮文案：

```text
完成
```

点击后：

- 如果有未确认的文字输入，先提交文字。
- 把原图和批注层合成为一张新图片。
- 上传新图片。
- 生成“批注结果”图片节点。
- 退出标注编辑态。

导出中：

- 按钮显示“导出中”。
- 工具栏其他操作禁用或不建议继续操作。

## 6. 用户完整交互流程

### 6.1 基础标注流程

1. 用户选中图片节点。
2. 点击“更多”。
3. 点击“标注”。
4. 普通图片工具栏隐藏。
5. 标注工具栏出现。
6. 用户使用画笔、箭头、矩形、圆形、文字进行标注。
7. 用户点击完成。
8. 系统导出批注图。
9. 系统创建“批注结果”图片节点。

### 6.2 添加箭头流程

1. 用户进入标注模式。
2. 点击箭头工具。
3. 在图片上按下鼠标作为箭头起点。
4. 拖到要指向的位置。
5. 松开鼠标。
6. 箭头绘制完成。

### 6.3 添加文字流程

1. 用户点击文字工具。
2. 在图片上点击希望放文字的位置。
3. 输入框出现。
4. 用户输入文字。
5. 按 Enter 或失焦确认。
6. 文字被绘制到批注层。

### 6.4 撤销和重做流程

1. 用户画了一个矩形。
2. 点击撤销。
3. 矩形消失。
4. 点击重做。
5. 矩形恢复。

## 7. 输出结果规则

### 7.1 默认生成新节点

标注完成后默认生成新的图片节点，不覆盖原图。

原因：

- 批注是沟通产物，不应该污染原素材。
- 用户可能还需要继续使用未标注的原图。
- 画布工作流需要保留处理链路。

### 7.2 新节点标题

默认标题：

```text
批注结果
```

### 7.3 新节点位置

新节点建议出现在原图片节点右侧或下游方向。

规则：

- 与原节点保持合理间距。
- 不完全重叠。
- 自动选中新节点。

### 7.4 自动连线

建议自动连接：

- source：原图片节点。
- target：批注结果节点。

### 7.5 新节点数据

建议保存：

```json
{
  "type": "result",
  "data": {
    "label": "批注结果",
    "resultType": "generateImage",
    "imageUrl": "批注结果图片地址",
    "imageUrls": ["批注结果图片地址"],
    "imageSource": "annotation",
    "imageSize": "图片尺寸",
    "sourceImageNodeId": "来源节点 ID",
    "sourceImageUrl": "原图地址",
    "annotationHasMarks": true
  }
}
```

## 8. 与 AI 修改的关系

标注工具本身只负责生成一张带批注的图片。

它可以作为后续 AI 修改的输入。

例如：

- 原图：商品图。
- 批注图：用户用红框圈出需要修改的区域，并写“换成蓝色”。
- 下游 AI 工具：读取原图和批注图，理解修改意图。

### 8.1 给 AI 的推荐输入

如果后续接 AI 图片修改，建议传：

- 原图。
- 批注图。
- 用户文字提示。

推荐提示词思路：

```text
请根据原图和批注图修改图片。
批注图中的标记用于指出需要处理的区域或内容。
请理解红框、箭头、文字说明的意图，并只修改相关区域。
```

### 8.2 不要误解为自动修改

标注工具完成后，只生成批注图。

它不会自动调用 AI 修改图片，除非用户接着使用局部修改、图片编辑或其他生成工具。

## 9. 技术实现建议

### 9.1 前端实现方式

推荐使用 canvas 批注层。

层级：

1. 原图片层。
2. 透明批注 canvas 层。
3. 文字输入框临时层。
4. 标注工具栏。

### 9.2 画布尺寸

批注 canvas 的显示尺寸应与图片显示区域一致。

为保证高清屏清晰：

- 使用 devicePixelRatio。
- canvas 实际像素 = 显示尺寸 x dpr。
- 绘制时用 transform 还原逻辑坐标。

### 9.3 坐标换算

鼠标事件坐标需要转换为 canvas 逻辑坐标。

需要考虑：

- 图片节点被画布缩放。
- 节点尺寸变化。
- 高分屏 dpr。
- canvas 实际像素和 CSS 尺寸不同。

### 9.4 绘制方式

画笔：

- 连续线段。
- lineCap = round。
- lineJoin = round。

箭头：

- 起点到终点绘制线段。
- 根据线宽计算箭头头大小。

矩形：

- strokeRect。

圆形：

- ellipse。

文字：

- fillText。
- 支持多行时按行绘制。

橡皮：

- 使用 destination-out 擦除批注层。
- 不影响原图。

### 9.5 历史记录

撤销/重做可以使用快照方案。

规则：

- 每次开始绘制前，把当前批注层保存为 undo 快照。
- 撤销时恢复上一个快照。
- 重做时恢复 redo 快照。
- 快照数量建议限制，例如最多 30 步。

### 9.6 导出合成

点击完成后：

1. 加载原图。
2. 创建输出 canvas。
3. 先绘制原图。
4. 再绘制批注 canvas。
5. 导出 PNG。
6. 上传文件。
7. 创建新图片节点。

### 9.7 跨域问题

如果原图跨域且没有正确 CORS，浏览器可能无法导出合成图。

开发需要确认：

- 图片是否来自同源文件服务。
- 图片 CDN 是否配置 CORS。
- 是否需要后端代理下载。
- 是否需要把外部图片先转存到本地素材服务。

## 10. 错误场景

### 10.1 图片为空

处理：

- 不允许进入标注。
- 提示“请先上传图片”。

### 10.2 图片加载失败

处理：

- 禁用标注入口。
- 或点击后提示“图片加载失败，无法标注”。

### 10.3 导出失败

原因可能是：

- 图片跨域。
- canvas 导出失败。
- 原图加载失败。

提示：

```text
批注图导出失败，请换一张允许导出的图片后再试。
```

### 10.4 上传失败

处理：

- 保留标注编辑态。
- 不丢失批注内容。
- 提示“批注图片上传失败，请重试”。

### 10.5 没有任何批注

如果用户没有绘制任何内容就点击完成，有两种方案：

方案 A：

- 允许导出。
- 结果等同于原图。

方案 B：

- 提示“请先添加批注”。
- 不导出。

建议一期采用方案 B，避免生成无意义节点。

## 11. 交互边界

### 11.1 与画布拖拽冲突

标注编辑态中：

- 在图片上拖动应绘制批注。
- 不应拖动画布。
- 不应拖动节点。
- 工具栏点击不应触发节点选择变化。

### 11.2 切换工具时的文字草稿

如果用户正在输入文字，然后点击其他工具：

- 应先提交当前文字。
- 如果文字为空，则丢弃。

### 11.3 取消时的文字草稿

如果用户正在输入文字并点击取消：

- 直接退出标注模式。
- 文字草稿不保存。

### 11.4 节点失去选中

如果节点失去选中：

- 可以退出标注模式。
- 或保持标注模式，具体由画布交互规则决定。

建议：

- 点击画布空白处退出标注模式。
- 如果有批注内容，可以后续加二次确认。

### 11.5 页面刷新

批注草稿属于临时状态。

页面刷新后：

- 不恢复未完成批注。
- 已完成生成的批注结果节点需要正常保存。

## 12. 键盘和可访问性

### 12.1 Escape

建议：

- 如果文字输入框打开，Escape 取消文字输入。
- 如果颜色面板打开，Escape 关闭颜色面板。
- 否则 Escape 退出标注模式。

### 12.2 Enter

文字输入时：

- Enter 确认文字。
- Shift + Enter 换行，可选。

### 12.3 Tab

工具栏按钮需要支持键盘聚焦。

推荐顺序：

1. 取消。
2. 画笔。
3. 箭头。
4. 矩形。
5. 圆形。
6. 文字。
7. 橡皮。
8. 颜色。
9. 线宽。
10. 撤销。
11. 重做。
12. 完成。

### 12.4 aria

按钮需要有清晰名称：

- 画笔。
- 箭头。
- 矩形。
- 圆形。
- 文字。
- 橡皮。
- 颜色。
- 线宽。
- 撤销。
- 重做。
- 完成批注。

## 13. 设计验收清单

设计稿需要包含：

- 图片节点普通工具栏中的标注入口。
- 点击标注后的编辑态。
- 标注工具栏完整布局。
- 每个工具 active 状态。
- 颜色面板展开态。
- 线宽滑杆。
- 撤销/重做禁用态。
- 文字输入框。
- 导出中状态。
- 导出失败提示。
- 完成后生成的批注结果节点。

## 14. 开发验收标准

### 14.1 入口

- 图片节点工具栏中可以进入标注。
- 进入标注后普通工具栏隐藏。
- 标注工具栏出现。

### 14.2 绘制

- 画笔可以绘制连续线。
- 箭头可以从起点指向终点。
- 矩形可以框选区域。
- 圆形可以圈出区域。
- 文字可以输入并显示在点击位置。
- 橡皮只擦除批注，不擦除原图。

### 14.3 样式

- 颜色选择能影响后续批注。
- 线宽能影响画笔、箭头、形状、橡皮和文字大小。
- 当前工具有 active 状态。

### 14.4 历史

- 撤销可以回退上一步。
- 重做可以恢复撤销内容。
- 新绘制后重做历史清空。

### 14.5 完成

- 点击完成后生成批注结果图片节点。
- 原图不变。
- 批注结果包含原图和批注内容。
- 新节点标题为“批注结果”。
- 新节点可以继续作为图片节点使用。

### 14.6 失败

- 导出失败时不创建空节点。
- 上传失败时不丢失批注内容。
- 失败后用户可以重试完成。

## 15. 测试用例建议

### 15.1 画笔测试

- 进入标注。
- 选择画笔。
- 绘制一条线。
- 点击完成。
- 检查结果图包含线条。

### 15.2 箭头测试

- 选择箭头。
- 从左上拖到右下。
- 检查箭头方向正确。

### 15.3 文字测试

- 选择文字。
- 点击图片。
- 输入文字。
- 按 Enter。
- 检查文字出现在点击位置。

### 15.4 橡皮测试

- 画一条线。
- 选择橡皮擦除部分。
- 检查原图不受影响。

### 15.5 撤销重做测试

- 画矩形。
- 点击撤销。
- 矩形消失。
- 点击重做。
- 矩形恢复。

### 15.6 导出失败测试

- 使用无法导出的跨域图片。
- 点击完成。
- 应提示失败。
- 不应创建空节点。
