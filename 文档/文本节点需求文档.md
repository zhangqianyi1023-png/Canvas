# 文本节点需求文档

## 1. 需求背景

在画布类创作工具中，文本节点不仅是普通的文字容器，也承担提示词、脚本、广告词、品牌文案、备注说明、创作中间稿等多种内容承载能力。

文本节点需要满足两类核心场景：

1. 用户手动输入、编辑和排版文本内容。
2. AI 生成文本后，用户可以继续修改、复制、保存到素材库，并作为后续图片、视频、音频等节点的输入素材。

本需求文档面向正式项目开发，不依赖任何原型代码实现。

## 2. 产品目标

文本节点的目标是成为画布中的轻量文本编辑单元，既能像便签一样快速记录，也能像提示词资产一样被复用、复制、保存和连接。

核心目标：

- 支持快速创建文本节点。
- 支持直接在节点内编辑文本。
- 支持基础文本格式化。
- 支持把文本保存到素材库。
- 支持复制文本内容。
- 支持文本节点作为其他生成节点的输入。
- 支持在画布中稳定移动、缩放、选择和连接。

## 3. 使用场景

### 3.1 手动记录

用户在画布中新增一个文本节点，输入灵感、备注、脚本片段或提示词。

### 3.2 AI 文本生成

用户通过文本生成器生成内容，生成结果以文本节点形式展示。用户可以继续编辑结果、复制内容，或保存到素材库。

### 3.3 文本作为生成输入

用户把文本节点连接到图片、视频、音频、3D 等生成节点，文本内容作为生成提示词或参考信息。

### 3.4 文本资产沉淀

用户将优质提示词、脚本、广告文案保存到素材库，后续可以从素材库重新拖入画布或用于其他生成任务。

## 4. 节点状态

### 4.1 空文本节点

当文本节点没有内容时，节点中展示空态提示：

- 主提示：双击输入文本
- 副提示：也可以打开生成器生成内容

交互要求：

- 双击空态区域进入编辑状态。
- 选中节点后可以移动、缩放、删除。
- 空节点也可以被连接，作为待补充内容占位。

### 4.2 编辑状态

用户双击文本内容或空态区域后进入编辑状态。

编辑要求：

- 支持直接输入文本。
- 支持粘贴文本。
- 支持多行文本。
- 支持基础 Markdown 或富文本格式。
- 编辑过程中不应触发画布拖拽。
- 编辑完成后，点击节点外或失焦保存内容。

### 4.3 展示状态

文本节点非编辑时展示格式化后的文本内容。

展示要求：

- 保留标题、正文、加粗、斜体、列表、分割线等基础格式。
- 文本过长时节点内部可滚动或支持放大查看。
- 节点背景色应作用于文本展示区域。

### 4.4 生成中状态

当文本由 AI 生成且任务未完成时，展示生成中骨架状态。

要求：

- 显示加载占位。
- 不允许用户覆盖编辑正在生成的内容。
- 如果支持流式输出，可以逐步显示生成文本。

### 4.5 放大查看状态

文本内容较长时，用户可以点击放大按钮进入大视图。

要求：

- 大视图内可阅读完整文本。
- 大视图内可继续编辑。
- 大视图编辑与节点内容保持同步。
- 关闭后回到画布原节点。

## 5. 工具栏需求

文本节点被选中、悬停或进入编辑时，应展示文本格式工具栏。

### 5.1 工具栏基础样式

工具栏应为浮层形式，出现在文本节点上方。

要求：

- 使用横向排列。
- 背景为深色半透明浮层。
- 按钮以图标或短文本展示。
- 按钮 hover 时显示 tooltip。
- 分组之间用竖线分隔。
- 不应遮挡文本编辑光标和主要内容。

### 5.2 工具栏按钮

工具栏建议包含以下功能：

| 功能 | 展示 | 说明 |
| --- | --- | --- |
| 背景颜色 | 调色图标 | 设置文本节点背景色 |
| H1 | 文本按钮 | 一级标题 |
| H2 | 文本按钮 | 二级标题 |
| H3 | 文本按钮 | 三级标题 |
| P | 文本按钮 | 正文 |
| 加粗 | B | 对选中文本加粗 |
| 斜体 | I | 对选中文本斜体 |
| 无序列表 | 图标 | 插入或切换无序列表 |
| 有序列表 | 图标 | 插入或切换有序列表 |
| 分割线 | 图标 | 插入分割线 |
| 添加标记 | 标签图标 | 给节点添加颜色标记 |
| 添加到素材库 | 文件夹图标 | 将文本保存到素材库 |
| 复制提示词 | 复制图标 | 复制文本内容 |
| 全屏编辑 | 全屏图标 | 打开大视图编辑 |

### 5.3 分组规则

工具栏分组建议如下：

1. 背景颜色。
2. 文本层级：H1、H2、H3、P。
3. 文本样式：加粗、斜体。
4. 列表与结构：无序列表、有序列表、分割线。
5. 节点操作：添加标记。
6. 内容资产操作：添加到素材库、复制提示词、全屏编辑。

分割规则：

- 添加标记左侧需要竖线分隔。
- 添加标记右侧也需要竖线分隔。
- 添加到素材库放在复制提示词左侧。
- 添加到素材库、复制提示词、全屏编辑属于内容操作区。

## 6. 文本编辑规则

### 6.1 支持格式

第一阶段建议支持：

- 一级标题
- 二级标题
- 三级标题
- 正文
- 加粗
- 斜体
- 无序列表
- 有序列表
- 分割线
- 多段落

不建议第一阶段加入过重能力，例如复杂表格、图片内嵌、多人协同批注等，避免文本节点变成完整文档编辑器。

### 6.2 格式存储

建议内部使用 Markdown 或可转换为 Markdown 的结构存储。

原因：

- 轻量。
- 易复制。
- 易作为提示词传给生成模型。
- 易导入导出。
- 比复杂富文本 JSON 更适合提示词和脚本文本场景。

### 6.3 粘贴规则

粘贴文本时：

- 如果当前选中的是文本节点，粘贴内容替换或插入到该文本节点中。
- 如果当前没有选中文本节点，在画布中心创建新的文本节点。
- 粘贴内容应优先保留纯文本和基础换行。
- 外部复杂格式可以降级为纯文本或 Markdown。

## 7. 背景颜色

文本节点支持设置背景颜色。

要求：

- 支持无背景。
- 支持若干预设颜色。
- 背景色作用于节点文本区域。
- 背景色不应影响工具栏可读性。
- 背景色数据应保存在节点数据中。

建议字段：

```json
{
  "textBackgroundColor": "yellow"
}
```

当用户选择“无背景”时，该字段为空字符串或不存在。

## 8. 添加标记

文本节点支持节点级标记。

要求：

- 标记用于区分节点状态或类别。
- 可以选择一个或多个颜色标记，具体数量由产品策略决定。
- 已添加标记时，工具栏按钮应有选中状态或角标提示。
- 标记是节点属性，不属于文本内容本身。

建议字段：

```json
{
  "tagColors": ["blue", "green"]
}
```

## 9. 添加到素材库

文本节点支持保存到素材库。

### 9.1 入口

入口位于文本格式工具栏中，位置在“复制提示词”左侧。

按钮要求：

- 使用文件夹或素材库图标。
- hover tooltip 为“添加到素材库”。
- 点击后打开保存到素材库弹窗。

### 9.2 保存内容

保存到素材库时，应保存以下信息：

```json
{
  "type": "text",
  "name": "文本素材名称",
  "prompt": "完整文本内容",
  "source": "canvas",
  "sourceId": "来源文本节点 ID",
  "groupId": "素材库文件夹 ID",
  "createdAt": "创建时间",
  "updatedAt": "更新时间"
}
```

说明：

- `type` 固定为 `text`。
- `prompt` 保存完整文本内容。
- `name` 默认可取文本前 24 个字符，也允许用户在保存弹窗中修改。
- 文本素材不要求 `imageUrl`。

### 9.3 保存弹窗

保存弹窗应复用现有素材库保存流程：

- 可选择个人或团队空间。
- 可选择文件夹。
- 可新建文件夹。
- 点击保存后写入素材库。

## 10. 复制提示词

文本节点支持复制内容。

要求：

- 点击“复制提示词”后，将文本节点完整内容写入剪贴板。
- 如果浏览器剪贴板 API 不可用，应使用兼容方案。
- 复制失败时不应导致节点异常。
- 可选：复制成功后显示轻提示。

复制内容建议使用纯文本或 Markdown，而不是 HTML。

## 11. 全屏编辑

文本节点支持全屏或大窗口编辑。

要求：

- 点击全屏按钮打开大视图。
- 大视图显示完整文本内容。
- 大视图内可编辑。
- 编辑保存后同步回原文本节点。
- 关闭大视图后回到画布。

适用场景：

- 长脚本。
- 长提示词。
- 多段广告文案。
- 需要更大编辑空间的内容。

## 12. 与生成节点的连接

文本节点应可作为其他节点的输入。

建议支持：

- 文本节点连接图片生成节点，作为图片提示词或参考文案。
- 文本节点连接视频生成节点，作为视频提示词、脚本或分镜描述。
- 文本节点连接音频生成节点，作为配音文案或歌词。
- 文本节点连接 3D 生成节点，作为对象或场景描述。

连接时应传递：

```json
{
  "nodeId": "文本节点 ID",
  "type": "text",
  "content": "文本内容"
}
```

## 13. 数据模型建议

文本节点建议数据结构：

```json
{
  "id": "node_xxx",
  "type": "result",
  "data": {
    "resultType": "generateText",
    "label": "文本",
    "result": "文本内容，建议为 Markdown 或纯文本",
    "textSource": "manual",
    "textBackgroundColor": "",
    "tagColors": [],
    "isGenerating": false
  },
  "position": {
    "x": 100,
    "y": 100
  },
  "style": {
    "width": 280,
    "height": 180
  }
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| resultType | 固定为 `generateText` |
| result | 文本内容 |
| textSource | 来源，可为 `manual`、`generated`、`copilot` 等 |
| textBackgroundColor | 背景色 |
| tagColors | 节点标记 |
| isGenerating | 是否生成中 |

## 14. 状态同步

文本节点内容变化时，应同步到：

- 节点自身数据。
- 画布保存数据。
- 相关连接输入。
- 如果文本由生成器生成，应同步生成器结果状态。

需要避免：

- 编辑中频繁触发全画布重渲染导致卡顿。
- 节点拖拽和文本编辑事件冲突。
- 外部点击导致正在输入的内容丢失。

## 15. 权限与异常

### 15.1 内容为空

如果文本为空：

- 复制按钮可禁用，或点击后无操作。
- 添加到素材库时应提示“文本内容为空，无法保存”。
- 全屏编辑仍可打开。

### 15.2 正在生成

如果文本正在生成：

- 不允许手动覆盖编辑，或需要明确提示。
- 允许停止生成后再编辑。

### 15.3 保存失败

保存到素材库失败时：

- 弹出错误提示。
- 保留用户当前文本内容。
- 不关闭保存弹窗，方便重试。

## 16. 第一阶段范围

第一阶段建议实现：

- 创建文本节点。
- 双击编辑文本。
- 文本展示与基础格式化。
- 背景色。
- 添加标记。
- 添加到素材库。
- 复制提示词。
- 全屏编辑。
- 粘贴文本创建节点。
- 粘贴文本更新选中文本节点。
- 文本节点连接到其他生成节点。

第一阶段暂不做：

- 多人实时协作编辑。
- 评论批注。
- 表格。
- 图片混排。
- 复杂文档分页。
- 文档级版本历史。

## 17. 验收标准

### 17.1 基础编辑

- 新建文本节点后，双击可输入文本。
- 输入多行文本后，节点展示正确。
- 点击节点外，内容不丢失。
- 再次双击可继续编辑。

### 17.2 格式工具栏

- 选中文本节点时展示工具栏。
- H1、H2、H3、P 可正常切换。
- 加粗、斜体、列表、分割线可正常应用。
- 背景色可正常设置和取消。
- 添加标记左侧和右侧有竖线分割。
- 添加到素材库按钮位于复制提示词左侧。

### 17.3 素材库

- 点击添加到素材库后打开保存弹窗。
- 可选择个人或团队空间。
- 可选择文件夹。
- 保存后素材库新增一条文本素材。
- 文本素材内容与节点内容一致。

### 17.4 复制

- 点击复制提示词后，剪贴板内容与文本节点内容一致。
- 空文本复制不会报错。

### 17.5 全屏编辑

- 点击全屏编辑后打开大视图。
- 大视图内容与节点内容一致。
- 在大视图编辑后，关闭时节点内容同步更新。

### 17.6 画布交互

- 文本节点可移动。
- 文本节点可缩放。
- 文本节点可删除。
- 文本节点可连接到其他生成节点。
- 文本编辑时不会误触发画布拖拽。

## 18. 技术实现建议

### 18.1 编辑器选择

建议使用轻量富文本编辑器，内部结果可转换为 Markdown。

原因：

- 用户需要基础格式，不需要完整文档编辑器。
- 生成模型更适合接收纯文本或 Markdown。
- Markdown 更容易复制、保存、传输。

### 18.2 事件隔离

文本编辑区域需要阻止画布拖拽事件冒泡。

关键点：

- 编辑器区域加 `nodrag`、`nopan` 类或等效事件隔离。
- 工具栏点击不应导致节点失焦。
- 工具栏浮层需要处理外部点击关闭。

### 18.3 性能

长文本编辑时，应减少不必要的全局状态更新。

建议：

- 输入过程中可本地维护草稿。
- 失焦或节流后同步到节点数据。
- 大文本渲染需要避免频繁重新解析。

## 19. 后续扩展

后续可以考虑：

- 文本节点模板。
- 一键改写、扩写、缩写。
- 翻译。
- 风格化改写。
- 提示词评分。
- 提示词版本记录。
- 文本与图片/视频节点的引用关系可视化。
- 从素材库拖入文本素材生成文本节点。
