# 添加标记完整设计文档

## 1. 功能定位

「添加标记」是画布节点的轻量分类能力。用户可以给图片、视频、文本、分组、素材堆、Playlist、3D 等节点添加一个或多个颜色标记，用来表达状态、优先级、分类或人工备注。

这个功能不改变节点内容本身，也不触发生成任务。它只做三件事：

- 在节点标题右侧显示颜色点，让用户一眼知道节点被打了哪些标记。
- 在画布顶部汇总当前画布已经使用过的标记颜色。
- 通过顶部颜色点快速高亮、查看和定位拥有该颜色标记的节点。

## 2. 核心原则

- 一个节点可以添加多个标记颜色。
- 同一个节点不能重复添加同一个颜色。
- 标记颜色是固定集合，不支持用户新增颜色。
- 标记名称可以修改，但修改的是显示名称，不是颜色本身。
- 顶部只展示已经被使用的颜色，没有任何节点使用的颜色不展示。
- 点击顶部颜色点是临时查看和定位，不是过滤隐藏节点。
- 所有节点类型的「添加标记」入口必须使用同一套颜色选择器组件，避免不同工具栏里的颜色排列、选中状态、hover 文案不一致。

## 3. 颜色集合

系统内置 6 个颜色，顺序固定。所有地方都按这个顺序展示和保存。

| 颜色 ID | 默认名称 | 色值 | 展示顺序 |
| --- | --- | --- | --- |
| red | 红色 | `#f45b69` | 1 |
| orange | 橙色 | `#ff9f43` | 2 |
| yellow | 黄色 | `#f4cf3b` | 3 |
| green | 绿色 | `#43d17a` | 4 |
| blue | 蓝色 | `#4aa3ff` | 5 |
| purple | 紫色 | `#9b5cf6` | 6 |

颜色用途不由系统强制定义，用户可以自行约定。例如红色表示待修改，黄色表示待确认，绿色表示已完成。

## 4. 节点工具栏入口

### 4.1 入口位置

不同节点的工具栏形态不同，但都使用同一个「添加标记」能力。

| 节点/工具栏 | 入口位置 | 按钮展示 |
| --- | --- | --- |
| 图片节点工具栏 | 图片节点工具栏中，靠近重新上传等操作前后，根据当前工具栏顺序展示 | icon-only |
| 视频节点 hover 工具栏 | 视频节点 hover 工具栏中 | icon-only 或紧凑按钮 |
| 文本节点格式工具栏 | 插入分割线之后、复制提示词之前 | icon-only |
| 其他节点 hover 工具栏 | 节点 hover 工具栏里，删除按钮之前 | icon-only 或紧凑按钮 |

### 4.2 未添加任何标记时

按钮表现：

- 按钮只显示「标记」图标，不显示文字。
- 按钮不显示任何颜色小点。
- 按钮不是选中态。
- hover 到按钮时显示 Tooltip：`添加标记`。
- 点击按钮后打开颜色选择下拉。

用户感知：

- 用户看到的是一个标记 icon。
- 鼠标悬停后，才知道这个按钮用于添加标记。

### 4.3 已添加一个或多个标记时

按钮表现：

- 按钮仍然只显示「标记」图标，不显示文字。
- 按钮右上角显示已添加颜色的小圆点。
- 最多在按钮上显示 3 个颜色小圆点。
- 小圆点横向排列。
- 小圆点顺序按系统颜色固定顺序排列，而不是按用户点击顺序排列。
- 按钮处于已标记状态，可通过 `aria-pressed` 或 active 状态表达。
- hover 到按钮时显示 Tooltip：`已 Pin：红色`、`已 Pin：红色、橙色`、`已 Pin：黄色、绿色、蓝色`。

文案规则：

- 没有任何颜色：`添加标记`
- 有颜色：`已 Pin：颜色名称`
- 多个颜色用中文顿号连接：`已 Pin：红色、橙色、黄色`
- 如果颜色名称被用户修改，Tooltip 使用修改后的名称。

示例：

- 节点添加了红色：hover 显示 `已 Pin：红色`
- 节点添加了红色和橙色：hover 显示 `已 Pin：红色、橙色`
- 用户把红色改名为「待修改」后：hover 显示 `已 Pin：待修改`

## 5. 颜色选择下拉

### 5.1 打开方式

用户点击节点工具栏里的「添加标记」按钮，打开颜色选择下拉。

下拉规则：

- 下拉标题语义为「节点标记颜色」。
- 下拉内展示 6 个固定颜色选项。
- 颜色选项必须横向或纵向的视觉规范保持一致，但颜色按钮本身的结构必须统一。
- 图片、视频、文本等所有入口必须使用同一套颜色选择器组件。
- 点击工具栏外部区域或按 Escape，关闭下拉。

### 5.2 下拉中的颜色选项结构

每个颜色选项包含：

- 左侧颜色圆点。
- 右侧颜色名称。
- 如果当前节点已经选中该颜色，颜色圆点上显示对勾 icon。
- 如果当前节点未选中该颜色，颜色圆点仍然显示该颜色，但不显示对勾 icon。

注意：

- 未选中颜色也必须显示颜色圆点。
- 不能因为未选中就只显示文字，否则用户看不出红色、橙色等颜色。
- 选中态和未选中态的差异是「是否有对勾」，不是「是否显示颜色」。

### 5.3 未选中状态

未选中颜色的表现：

- 左侧显示对应颜色圆点。
- 圆点中没有对勾。
- 颜色名称正常显示。
- 选项背景为默认透明或弱背景。
- hover 该选项时，背景轻微变亮。

点击后：

- 给当前节点添加该颜色。
- 节点标题右侧立刻出现该颜色点。
- 按钮 Tooltip 立刻从 `添加标记` 变为 `已 Pin：颜色名称`。
- 如果这是画布中首次使用该颜色，画布顶部立刻出现该颜色点。
- 下拉关闭。

### 5.4 选中状态

选中颜色的表现：

- 左侧显示对应颜色圆点。
- 圆点中显示对勾 icon。
- 选项可以有 active 背景，用来辅助表达选中。
- 颜色名称正常显示。

点击后：

- 从当前节点移除该颜色。
- 节点标题右侧对应颜色点消失。
- 如果节点仍有其他颜色，按钮 Tooltip 更新为剩余颜色。
- 如果节点没有任何颜色，按钮 Tooltip 恢复为 `添加标记`。
- 如果画布中没有其他节点使用该颜色，顶部对应颜色点消失。
- 下拉关闭。

### 5.5 多颜色行为

一个节点可以同时选中多个颜色。

规则：

- 每次点击颜色选项只切换当前颜色，不影响其他颜色。
- 多个颜色点在节点标题右侧全部展示。
- 工具栏按钮上最多展示 3 个颜色点。
- 节点标题右侧可以展示该节点拥有的所有颜色点。
- 顶部汇总按全画布维度统计，不按当前节点统计。

## 6. 节点标题右侧颜色点

### 6.1 未添加标记

节点标题区域只显示：

- 节点类型或标题 icon。
- 节点名称。
- 其他已有标题附加状态，例如合规 icon 等。

不显示标记颜色点。

### 6.2 添加标记后

节点标题右侧显示颜色点。

显示规则：

- 颜色点显示在节点名称后方。
- 如果标题后方还有其他状态，例如「已合规」icon，应遵循具体功能规则，不要挤占标记颜色点的位置。
- 每个颜色一个圆点。
- 多个圆点横向排列。
- 颜色点之间有小间距。
- 颜色点带轻微描边，避免在深色或同色背景上看不清。
- 颜色点不响应点击，只是状态展示。
- hover 到颜色点时，可以显示浏览器默认 title，例如 `红色`。

### 6.3 标题改名时

用户点击节点标题进入改名输入态时：

- 标题输入框出现。
- 标记颜色点暂时不展示，避免干扰标题编辑。
- 标题保存或取消后，颜色点恢复展示。
- 标题名称变化后，顶部标记下拉里的节点名称同步更新。

## 7. 画布顶部颜色汇总

### 7.1 出现条件

画布顶部的标记颜色点只在有节点使用该颜色时出现。

规则：

- 如果没有任何节点添加标记，顶部不显示标记颜色栏。
- 如果只有红色被使用，顶部只显示红色点。
- 如果红色、黄色、绿色被使用，顶部只显示这三个颜色点。
- 已使用颜色按固定颜色顺序排列。
- 删除节点或取消标记后，如果某颜色没有任何节点使用，该颜色点从顶部消失。

### 7.2 顶部颜色点默认状态

默认状态：

- 颜色点位于画布顶部居中区域。
- 每个颜色点外层是深色圆形底座。
- 内层是实际颜色圆点。
- 未选中时没有白色描边。
- 不展示文字。

### 7.3 hover 顶部颜色点

hover 某个顶部颜色点时：

- 颜色点外层出现白色描边或高亮描边。
- 下方显示 Tooltip。
- Tooltip 文案格式：`颜色名称 · N 个节点`。

示例：

- `红色 · 3 个节点`
- `待修改 · 5 个节点`
- `已完成 · 1 个节点`

如果颜色名称被修改，Tooltip 使用修改后的名称。

### 7.4 点击顶部颜色点

点击顶部颜色点后：

- 顶部颜色点进入选中态。
- 该颜色点显示白色描边。
- 打开该颜色的下拉面板。
- 画布中所有拥有该颜色标记的节点显示同色描边。
- 其他颜色标记的节点不高亮，除非它们同时拥有当前颜色。

再次点击同一个已打开的颜色点：

- 如果当前颜色已经打开且处于选中态，则关闭下拉。
- 取消该颜色点选中态。
- 取消所有节点的颜色描边高亮。

点击另一个颜色点：

- 关闭上一个颜色下拉。
- 打开新颜色下拉。
- 取消上一个颜色的节点描边。
- 高亮新颜色对应的所有节点。

### 7.5 点击画布空白处

当顶部颜色下拉已打开时，点击画布空白处：

- 关闭下拉面板。
- 取消顶部颜色点选中态。
- 取消所有节点颜色描边高亮。

这是必须行为，避免出现「下拉没了，但顶部颜色点还像被选中」的误解。

## 8. 顶部颜色下拉面板

### 8.1 面板打开位置

面板出现在被点击的顶部颜色点下方。

视觉规则：

- 面板宽度约 260px。
- 背景为深色浮层。
- 圆角约 14px。
- 有轻微边框和阴影。
- 面板不跟随画布缩放。
- 面板不遮挡顶部颜色点本身。

### 8.2 面板结构

面板分为两部分：

1. 头部区域。
2. 节点列表区域。

头部区域包含：

- 当前颜色小圆点。
- 当前颜色名称。
- 修改名称按钮。
- 节点数量。

节点列表区域包含：

- 所有拥有该颜色标记的节点。
- 每个节点一行。
- 每行包含节点类型 icon 和节点名称。

### 8.3 头部默认态

头部默认态显示：

- 左侧颜色点。
- 中间颜色名称，例如 `红色`。
- 名称右侧有编辑 icon。
- 右侧显示数量，例如 `3 个节点`。

字号规则：

- 颜色名称字号约 14px。
- 节点数量为弱文本，靠右显示。

### 8.4 点击修改名称

点击编辑 icon 后：

- 颜色名称从文本变成输入框。
- 输入框自动聚焦并选中文本。
- 编辑 icon 变成确认 icon。
- 用户可以输入新的标记名称。
- 最大长度 16 个字符。

提交规则：

- 按 Enter：保存名称。
- 点击确认 icon：保存名称。
- 输入框失焦：保存名称。
- 按 Escape：取消编辑，恢复进入编辑前的名称。

保存后的表现：

- 下拉头部标题立刻更新为新名称。
- 顶部 hover Tooltip 立刻更新为新名称。
- 节点工具栏按钮 hover 的 `已 Pin：...` 文案也应使用新名称。
- 节点标题右侧颜色点不变，因为颜色没有变。
- 节点与颜色的关联不变。

清空输入：

- 如果保存时输入为空，恢复默认名称。
- 例如红色清空后恢复为 `红色`。

### 8.5 节点列表

节点列表展示当前颜色下的全部节点。

每一行包含：

- 节点类型 icon。
- 节点展示名称。

节点名称规则：

- 优先展示节点自定义标题。
- 没有自定义标题时，展示节点类型默认名称，例如 `图片`、`视频`、`文本`、`Playlist`、`3D Viewfinder`。
- 如果名称过长，单行省略。

hover 节点列表项：

- 当前行背景变亮。
- 鼠标为可点击状态。

点击节点列表项：

- 画布定位到对应节点。
- 对应节点进入选中状态。
- 关闭当前下拉面板。
- 清除顶部颜色点选中态。
- 清除节点颜色描边高亮。

定位动画：

- 画布平滑移动到目标节点。
- 目标节点在视图中居中或接近居中。

## 9. 节点高亮描边

点击顶部颜色点后，所有拥有该颜色的节点显示高亮描边。

高亮样式：

- 节点边框颜色变成当前标记颜色。
- 节点外侧显示同色 outline。
- 节点周围有轻微同色光晕。
- 节点标题文字保持可读。

规则：

- 同一时间只高亮一种颜色。
- 如果节点同时拥有多个标记，只要包含当前颜色，就显示当前颜色描边。
- 高亮只用于查看，不改变节点选中状态。
- 高亮关闭后，节点恢复原本边框状态。

## 10. 数据设计

### 10.1 节点标记数据

每个节点保存自己的颜色列表。

示例：

```json
{
  "tagColors": ["red", "yellow"]
}
```

规则：

- `tagColors` 是数组。
- 数组里只保存颜色 ID，不保存颜色名称和色值。
- 非法颜色 ID 会被过滤。
- 同一个颜色 ID 不重复保存。
- 空数组表示没有标记。

### 10.2 画布级标记名称数据

颜色名称属于画布级数据。

示例：

```json
{
  "tagColorLabels": {
    "red": "待修改",
    "green": "已完成"
  }
}
```

规则：

- 只保存被用户修改过的名称。
- 没修改过的颜色使用默认名称。
- 名称为空时删除自定义名称，恢复默认名称。
- 每个名称最多 16 个字符。
- 不同画布可以有不同的颜色名称。

## 11. 关闭与冲突规则

### 11.1 节点颜色下拉

以下行为关闭节点颜色下拉：

- 点击某个颜色选项。
- 点击工具栏外部。
- 按 Escape。
- 打开同工具栏中的其他菜单。
- 节点失去当前 hover 或选中上下文。

### 11.2 顶部颜色下拉

以下行为关闭顶部颜色下拉：

- 点击画布空白处。
- 按 Escape。
- 点击节点列表项并完成定位。
- 再次点击当前打开的颜色点。
- 当前颜色已经没有任何节点使用。

关闭顶部颜色下拉时，必须同时取消节点颜色描边高亮。

### 11.3 和节点选中态的关系

- 添加标记不会改变节点选中状态。
- 顶部颜色高亮不会改变节点选中状态。
- 点击顶部下拉里的节点列表项，才会改变节点选中状态。
- 节点被选中后，原有节点工具栏逻辑照常显示。

### 11.4 和删除节点的关系

删除节点后：

- 该节点上的标记关系消失。
- 顶部统计数量减少。
- 如果某个颜色数量变为 0，该颜色点从顶部消失。
- 如果当前打开的正是该颜色下拉，应该关闭下拉并取消高亮。

### 11.5 和复制节点的关系

复制节点时建议复制 `tagColors`。

原因：

- 用户复制一组已分类节点时，通常希望分类状态也保留。
- 顶部统计数量随复制结果增加。

## 12. 可访问性与文案

### 12.1 按钮可访问名称

未添加标记：

- `aria-label`: `添加标记`
- Tooltip: `添加标记`

已添加标记：

- `aria-label`: `已 Pin：红色`
- Tooltip: `已 Pin：红色`

顶部颜色点：

- `aria-label`: `红色，3 个节点`

颜色选择项：

- 使用 `menuitemcheckbox` 语义。
- 已选中时 `aria-checked=true`。
- 未选中时 `aria-checked=false`。

### 12.2 文案清单

| 场景 | 文案 |
| --- | --- |
| 未标记按钮 hover | 添加标记 |
| 已标记按钮 hover | 已 Pin：红色、橙色 |
| 颜色选择下拉 | 节点标记颜色 |
| 顶部颜色 hover | 红色 · 3 个节点 |
| 顶部下拉标题 | 红色 |
| 顶部下拉数量 | 3 个节点 |
| 修改名称输入框 | 标记名称 |

## 13. 验收清单

### 13.1 节点工具栏

- 未添加标记时，hover 按钮显示 `添加标记`。
- 添加红色后，hover 按钮显示 `已 Pin：红色`。
- 添加多个颜色后，hover 按钮按固定颜色顺序显示多个名称。
- 图片、视频、文本等所有入口的下拉颜色排列一致。
- 所有入口的未选中颜色都显示颜色圆点。
- 已选中颜色显示对勾。
- 点击未选中颜色可以添加标记。
- 点击已选中颜色可以取消标记。

### 13.2 节点标题

- 未添加标记时，标题右侧不显示颜色点。
- 添加一个标记后，标题右侧显示一个颜色点。
- 添加多个标记后，标题右侧显示多个横向颜色点。
- 取消某个标记后，对应颜色点消失。
- 编辑标题时不影响标记数据。
- 标题保存后，顶部下拉里的节点名称同步更新。

### 13.3 顶部颜色栏

- 没有任何标记时，顶部颜色栏不显示。
- 某颜色至少被一个节点使用后，顶部出现该颜色点。
- hover 顶部颜色点显示 `颜色名称 · N 个节点`。
- 点击顶部颜色点后打开下拉。
- 点击顶部颜色点后，对应节点显示同色描边。
- 点击画布空白处后，下拉关闭，描边消失，顶部颜色点不再选中。

### 13.4 顶部下拉

- 下拉头部显示颜色点、名称、编辑按钮和节点数量。
- 点击编辑按钮后名称变成输入框。
- 输入新名称后按 Enter 可以保存。
- 点击确认 icon 可以保存。
- 输入框失焦可以保存。
- 按 Escape 可以取消编辑。
- 清空名称后恢复默认名称。
- 修改名称后 hover 文案、下拉标题、已 Pin 文案同步更新。
- 点击节点列表项后，画布定位到该节点并选中该节点。

## 14. 非目标范围

当前版本不做：

- 不支持新增自定义颜色。
- 不支持删除默认颜色。
- 不支持调整颜色顺序。
- 不支持真实过滤隐藏节点。
- 不支持按标记批量删除节点。
- 不支持批量给多个节点添加标记。
- 不支持为单个节点设置自定义标记名称。
- 不支持跨画布共享标记名称。
- 不支持权限、协作冲突、多人编辑历史。

## 15. 后续扩展方向

后续可以考虑：

- 多选节点后批量添加标记。
- 按标记筛选显示或隐藏节点。
- 顶部标记支持搜索。
- 标记支持用户自定义颜色。
- 标记支持拖拽排序。
- 标记面板支持统计不同节点类型数量。
- 协作场景显示谁添加了标记。
- 标记变更进入撤销/重做历史。
